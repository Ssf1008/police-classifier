## 数据流详解

### 请求流程

```
用户在 Dify 输入
    ↓
incident_text = "小区内两人发生争执并有肢体冲突"
    ↓
Dify 构建 HTTP 请求
    ↓
POST http://localhost:8000/classify
Content-Type: application/json

{
  "query": "小区内两人发生争执并有肢体冲突",
  "top_k": 5,
  "llm_provider": "openai"
}
    ↓
FastAPI 接收请求
    ↓
api_server.py 的 classify() 函数处理
    ↓
创建 RAGIncidentClassifier 实例
    ↓
调用 clf.classify()
```

### 分类流程

```
clf.classify(query, top_k=5)
    ↓
1. 检索相似案例
   clf.retrieve(query, top_k=5)
       ↓
   ChromaDB 向量搜索
       ↓
   返回 Top-5 相似案例
    ↓
2. 构建提示词
   format_cases_for_prompt(cases)
       ↓
   生成 LLM 输入
    ↓
3. 调用 LLM
   llm.invoke([system_prompt, user_prompt])
       ↓
   硅基流动 API (OpenAI 兼容)
       ↓
   返回分类结果
    ↓
4. 解析输出
   json.loads(response)
       ↓
   提取 category, confidence, reason
    ↓
5. 返回结果
   {
     "category": "治安案件",
     "confidence": 0.95,
     "reason": "...",
     "similar_cases": [...]
   }
```

### 响应流程

```
FastAPI 返回 JSON 响应
    ↓
HTTP 200 OK
Content-Type: application/json

{
  "category": "治安案件",
  "confidence": 0.95,
  "reason": "新警情与参考案例...",
  "similar_cases": [
    {
      "id": "case_001",
      "label": "治安案件",
      "score": 0.876,
      "text": "..."
    },
    ...
  ]
}
    ↓
Dify HTTP 节点接收响应
    ↓
输出节点解析数据
    ↓
展示给用户
```

## 故障排查流程

```
问题：Dify 无法连接到 API
    ↓
检查 1：PyCharm 中的 api_server.py 是否运行？
    ├─ 是 → 检查 2
    └─ 否 → 启动 api_server.py
    ↓
检查 2：URL 是否正确？
    ├─ http://localhost:8000/classify ✓
    └─ 否 → 修改为正确的 URL
    ↓
检查 3：防火墙是否阻止？
    ├─ 是 → 允许 8000 端口
    └─ 否 → 检查 4
    ↓
检查 4：查看 PyCharm 终端的错误日志
    ├─ 有错误 → 根据错误信息修复
    └─ 无错误 → 联系技术支持
```
